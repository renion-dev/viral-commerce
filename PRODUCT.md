# Product

## What It Is

A living 3D website that transforms emerging cultural signals into interactive commerce experiences.

## What It Is Not

- A traditional e-commerce store
- A blog
- A social network
- A static landing page

## User Journey

```
LANDING (3D World View)
    │
    ├── Explore → Rotate/zoom 3D scene
    ├── Discover → Click objects → Stories/Products
    ├── Create → Generate personal artifact
    ├── Share → Share artifact/screenshot
    └── Buy → Affiliate link / digital product
```

## Core Features (MVP)

### 1. Living Homepage
- 3D scene reflecting current world state
- Real-time trend indicators
- Interactive objects (clickable, explorable)

### 2. Dynamic Content
- World state changes based on signals
- Products/stories auto-generated
- No manual CMS editing needed

### 3. Viral Mechanics
- Shareable artifacts (images, cards)
- Personalized world views
- Social proof integration

### 4. Commerce
- Affiliate product integration
- Digital product delivery
- Scarcity/urgency mechanisms

### 5. Analytics
- Interaction tracking
- Conversion measurement
- Experiment results

## MVP Scope

**Must have:**
- [ ] 3D homepage with interactive objects
- [ ] Dynamic world state (JSON-driven)
- [ ] Signal discovery (at least 1 source)
- [ ] Opportunity scoring
- [ ] Content generation pipeline
- [ ] Share mechanism
- [ ] At least 1 monetization path
- [ ] Analytics
- [ ] Public deployment

**Post-MVP:**
- Multiple signal sources
- Advanced experiments
- More monetization paths
- User accounts
- Community features

## Success Criteria

| Criterion | Measurement |
|-----------|-------------|
| Works publicly | URL accessible, HTTPS |
| 3D renders | Scene loads, objects interactive |
| Content dynamic | World state changes without code deploy |
| Viral mechanism | Share links work, artifacts generate |
| Monetization | At least 1 revenue path active |
| Autonomous | Cron jobs running signal discovery |
