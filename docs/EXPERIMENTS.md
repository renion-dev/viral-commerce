## Experiment Template

```markdown
### EXP-NNN: [Name]

**Status:** planned | running | complete
**Hypothesis:** If we do X, then Y will happen
**Metric:** What we measure
**Baseline:** Current value
**Variant:** What we're testing
**Success Threshold:** Minimum improvement to continue
**Duration:** How long to run
**Result:** (filled when complete)
**Decision:** keep | modify | kill
```
